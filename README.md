One debugging haiku, strict 5-7-5 syllables, written by a small deterministic program for the "Seventeen Syllables of Debugging" bounty on make.fun.

> One semicolon
> hidden where the loop begins
> three hours, one keystroke

## Run it

```sh
node main.ts
```

It writes the haiku to `/output/entry.txt` (70 characters, 3 lines, 5-7-5).
